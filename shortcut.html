단축어 받기
웨이보 · 샤오홍슈 · 도우인 게시물의 사진, 라이브포토, 영상을 사진 앱에 바로 저장
아래 버튼을 누르고 단축어 추가를 누르면 설치 완료
웨이보 · 샤오홍슈 · 도우인 다운로드 단축어 받기 ↗
초기 설정 방법
① 스크립트 실행 허용 도우인용
  • 설정 → 앱 → 단축어 → 고급 → 스크립트 실행 허용 켜기
② 공유 시트에서 보기 도우인용
  • 단축어 앱에서 단축어 'WBXHDY'를 길게 누르기 → 세부사항 → 공유 시트에서 보기 켜기
③ Safari 데스크탑 설정 도우인 라이브사진 저장용
  • Safari 주소창에 www.douyin.com 직접 입력 후 열기 → 주소창 왼쪽 가가(aA) → 웹 사이트 설정 → 데스크탑 웹 사이트 요청 켜기
  • 가가(aA)를 누르면 바로 보이는 '데스크탑 웹 사이트 요청'은 지금 화면에만 한 번 적용되고 다시 열면 풀리니, 꼭 웹 사이트 설정 안의 스위치로 켜야 계속 적용됨
처음 실행하면 사이트 접근, 스크립트 실행, 사진 저장 권한 허용 필요 모두 항상 허용 선택
사용법
빠른 실행 설정
  • 뒷면 탭: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭 or 삼중 탭 → 단축어 'WBXHDY' 설정
  • 제어 센터: 제어 센터 편집 → 컨트롤 추가 → 단축어 → 'WBXHDY' 선택
웨이보 · 샤오홍슈
  • 1. 웨이보/샤오홍슈에서 게시글 링크 복사
  • 2. 뒷면 탭 / 제어 센터로 단축어 실행 → 저장 완료 알림 확인
웨이보 게시물은 사진 저장 시 원본 그대로 / 워터마크 삭제 중 선택 가능
도우인
  • 1. 도우인 앱에서 공유 → 링크 복사
  • 2. 뒷면 탭 / 제어 센터로 단축어 실행 → Safari 열림
  • 3. Safari 자체 공유 버튼 → WBXHDY 선택 → 저장 완료 알림 확인
Safari 공유 버튼을 누른 뒤 하단의 동작 편집에서 단축어를 즐겨찾기에 넣으면 최상단에서 바로 선택할 수 있음
알림 · 오류 사항
링크를 찾지 못함
복사한 내용에 웨이보·샤오홍슈·도우인 게시물 링크가 없을 때 뜸. 앱에서 링크 복사를 다시 누른 뒤 실행
저장할 사진/영상 없음
삭제된 게시물, 로그인해야 볼 수 있는 게시물(팔로워 공개 등), 글만 있는 게시물일 때 뜸
도우인 사진/영상을 찾지 못함
  • Safari 페이지가 다 열린 뒤에 다시 실행
  • 도우인 라이브포토 게시물이면 Safari 데스크탑 설정이 켜져 있는지 확인
  • 단축어 설정에서 스크립트 실행 허용이 켜져 있는지 확인
도우인에서 링크 복사 후 Safari에서 열리는 현상
오류가 아닌 도우인 구조 특성상 Safari 페이지 경유 필요. Safari 자체 공유 버튼 → 단축어 선택
공유 시트에 단축어가 안 보임
공유 시트 맨 아래 동작(작업) 편집에서 단축어가 켜져 있는지 확인 또는 단축어 세부사항의 공유 시트에서 보기 켜기.

사용이 불가능할 때는 팬가이드에 있는 위챗 미니프로그램 사용을 참고 해주세요

  • 도우인: 게시물 원본 크기 사진 · 영상 720p
